# Listen · 云端音乐一键转存面板

一个自托管的网页面板：**搜歌 → 点一下 → 自动下载成 MP3 → 直接存进你的天翼云盘**。
手机、电脑浏览器都能用，不用装 App，不占本地空间，播放时手机直连云盘 CDN（302 重定向，服务器零流量中转）。

启动后自动探测当前网络能用哪些音源，能用谁就用谁，**无需任何配置**即可开箱。

---

## 功能

- 🔍 **多音源搜索**：聚合音源（320k 高音质）、公益镜像、网易云、B 站、YouTube，自动优选可用源。
- ☁️ **扫码登录天翼云盘**：不碰密码，扫码即授权，歌曲直接存进你的云盘。
- 📥 **一键转存**：后台自动下载并上传，实时进度可见，失败自动重试。
- 🎵 **内置播放器**：云盘里的歌自动成列表，支持播放 / 上一首 / 下一首 / 拖拽进度，可直接删除云盘歌曲，列表自动同步。
- 📱 **手机 / 电脑双端适配**：电脑是左侧栏，手机自动变底部导航；播放控制就在列表上方，不用低头找。
- 💬 **不挡屏幕的任务提示**：转存时右下角一个小气泡（带进度环），点开才看详情，没有任务时自动消失。
- 🕘 **搜索历史 + 封面**：上次搜的结果重开页面还在，歌曲封面直接显示。
- ⚙️ **可自定义**：音质选择、自定义公益镜像、可选上传 YouTube 凭证提速、保存位置可改。

## 音源（自动探测，无需配置）

| 音源 | 适用环境 | 说明 |
|---|---|---|
| 聚合音源（GD） | 大部分网络 | 聚合网易/QQ 等平台，最高 320k 高音质 |
| 公益镜像 | 海外网络 | 无需设置，2~4 分钟/首 |
| 网易云音乐 | 国内网络 | 中文曲库最全，VIP 歌自动跳过 |
| B 站音乐区 | 国内网络 | MV / 翻唱 / 演唱会资源多 |
| YouTube 直连 | 海外 + cookie | 上传 cookies.txt 后 30 秒/首 |

部署后 1 分钟内完成首次体检（设置页可看实时结果），每 30 分钟复检，源挂了自动切换。
判定标准是「真的能下载」，不是 ping 得通。

### 公益镜像失效了怎么办？

设置 → 「自定义公益镜像」→ 填一个 Invidious 实例域名（如 `invidious.example.com`，不带 https://）→ 添加。
系统自动体检，可用即生效。实例名单可在 `api.invidious.io` 查询。

## 部署方式

### 方式一：Docker（推荐，最简单）

```bash
# 直接拉镜像运行（AMD64 / ARM64 双架构均支持）
docker run -d --name listen \
  -p 8000:8000 \
  -v listen-data:/data \
  tianjian518/listen:1.1.0

# 或用 docker-compose
# 1) 下载 docker-compose.yml
# 2) 执行：docker compose up -d
```

浏览器打开 `http://<你的服务器IP>:8000`，按页面提示扫码登录天翼云盘即可使用。

> 数据（登录态 + 临时下载）持久化在 `listen-data` 卷里，重启不丢。

### 方式二：源码运行

```bash
# 1. 装系统依赖（ffmpeg + chromium 用于扫码登录）
sudo apt install -y ffmpeg chromium python3-venv

# 2. 建虚拟环境并装依赖
python3 -m venv /opt/venv && /opt/venv/bin/pip install -r requirements.txt

# 3. 启动（默认 8000 端口，可用 PORT 环境变量改）
PORT=8000 /opt/venv/bin/uvicorn app:app --host 0.0.0.0
```

首次打开页面会生成 `config.json`，之后你的登录态和设置都写在里面（请妥善保管，勿外泄）。

## 怎么用（4 步）

1. **连云盘**：点右上角「连接天翼云盘」→ 屏幕出现二维码 → 手机打开**天翼云盘 App** → 扫一扫 → 点「确认登录」。
2. **搜歌**：输入歌名或歌手，回车。
3. **转存**：喜欢的点「转存到云盘」。右下角会冒出小气泡，点开可看实时进度，下载 + 上传全自动。
4. **听歌**：侧边栏点「播放器」，云盘里的歌自动成列表，点歌即播。

默认存到云盘 `我的音乐` 文件夹（没有会自动创建）。换位置：右上角云盘按钮 → 「更改保存位置」。

## 常见问题

- **二维码扫不了 / 过期了**：约 2 分钟失效，点「换个二维码」重新来。
- **一首歌要等多久？** 默认走公益音源约 2~4 分钟，可上传 YouTube 凭证提速到 30 秒内（可选，不上传也完全能用）。
- **播放器里的歌和云盘不一致？** 在播放器页点「刷新」，或在云盘删歌后等 30 秒自动同步。
- **转存失败？** 看右下角任务框的红色文字，公益音源偶尔抽风，重试一次通常就好。

## 技术说明

- 播放采用 **302 重定向**：手机/浏览器直接连天翼 CDN 拉流，服务器只出一次跳转，音频流量不经过本机。
- 天翼云盘走网页版内部接口（官方无公开 API），官方改版可能失效，失效会修。
- 下载的音乐仅供**个人备份**使用，请勿商用或二次分发。

## 目录结构

```
listen/
├── app.py                  # 网页后端（FastAPI）
├── core/
│   ├── tianyi.py           # 天翼云盘对接：扫码会话 / 分片上传 / 目录
│   ├── qrlogin.py          # 扫码登录（无头浏览器截二维码）
│   ├── media.py            # 搜索 + 下载转 MP3
│   ├── tasks.py            # 转存任务队列
│   ├── probe.py            # 音源自动探测
│   ├── sources/            # 各音源实现
│   └── store.py            # 配置存储
├── static/                 # 网页界面
├── Dockerfile              # 容器构建
├── docker-compose.yml      # 一行起服务
└── requirements.txt
```

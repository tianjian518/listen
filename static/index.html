可选加速：借用你浏览器的「YouTube 通行卡」（30秒/首）

原理一句话：YouTube 对陌生服务器很警惕，但你是它的老熟人（你登录过）。 把你浏览器里的「通行卡」导出来交给面板，面板就能借用这个身份去拿歌。

安全说明：全程不用输入 Google 密码，导出的只是一张访问凭证， 只存在这台服务器上，随时可以一键删除。

1在电脑的 Chrome 或 Edge 浏览器里打开 youtube.com，确认右上角是登录状态
2点浏览器右上角的「拼图」图标 → 打开应用商店 → 搜索安装 Get cookies.txt LOCALLY（认准这个名字，免费无广告）
3回到 youtube.com 页面，再点拼图图标 → 点 Get cookies.txt LOCALLY → 点 Export 按钮
4电脑会下载一个 cookies.txt 文件 → 点下面按钮，选中它上传，完成

不上传也完全能用（走公益镜像，一首约 2~4 分钟）； 上传后转存走 YouTube 直连，一首 30 秒内。凭证一般能用好几个月。

如果「公益镜像」显示不可用，可以添加社区里其他人架设的 Invidious 实例。
格式：只填域名，例如 invidious.example.com（不用带 https://，不要带路径）。
实例名单可在 api.invidious.io 或 instances.cobalt.best 查询。 添加后自动体检，可用即生效，不可用会如实显示。
